Aki's Gif-inator 1.2.0 adds two detail choices:

- **Smooth · 720px · 20 fps** favors smoother motion at a moderate resolution.
- **Sharp · 960px · 15 fps** favors finer detail with fewer frames.

Both use Sierra dithering and respect the source's dimensions and frame rate.
All existing presets remain available; High is still the default. Auto-fit size
remains optional and may reduce resolution, frame rate or colors to fit a target.

Download **Akis-Gif-inator-1.2.0-windows-x64-setup.exe**, close the app, and run
Setup to update the existing installation. User exports are preserved.
The source ZIP and SHA256SUMS.txt accompany the installer.
