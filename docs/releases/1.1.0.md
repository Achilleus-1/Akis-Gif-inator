Aki's Gif-inator 1.1.0 adds remembered dark glass and a normal Windows installation flow.

### Windows download
Download **Akis-Gif-inator-1.1.0-windows-x64-setup.exe**, run Setup and launch from
the Start menu or optional desktop shortcut. Windows 10/11 x64; no administrator
account or manual Python commands are required. Uninstall via Installed apps.

Internet is needed for installation: Setup downloads a private Python/Qt runtime
from Python.org/PyPI and reuses FFmpeg on PATH, or obtains a pinned Gyan build.
Publisher SHA-256 hashes are checked before extraction. The installed app works
offline and does not change system Python or PATH. User exports survive uninstall.

### Changes
- Dark mode covers controls, previews, timeline and live/still glass, and remembers the choice locally.
- Correct OpenGL float-uniform handling for animated glass and theme switching.
- Standard per-user Windows setup, shortcuts, uninstall and versioned release assets.
- Pinned upstream dependency URLs/hashes, safe extraction and installer/export/uninstall checks.
- Clear end-user download instructions, source/developer documentation and dependency notices.

### Assets
- Windows setup EXE: normal user installation; dependencies fetched upstream.
- Source ZIP: contributors and people who prefer running the source.
- SHA256SUMS.txt: integrity hashes for the downloadable assets.

The setup EXE is currently unsigned. The release does not disable Windows security.
Python, Qt and FFmpeg binaries are not rehosted inside the setup EXE or Git source tree.
