# Code of conduct

Be respectful and constructive. Discuss behavior and evidence, help newcomers,
and credit the people whose work you adapt. Harassment, discrimination, threats,
unwanted sexual attention and sharing another person's private information are
not welcome in this project's issues, pull requests or discussions.

Maintainers may edit or remove inappropriate content and restrict participation.
Report concerns privately using [Achilleus's contact links](https://linktr.ee/achilleus_).
Do not repeat private information in a public report. This policy applies to
project spaces and project-related interactions.
